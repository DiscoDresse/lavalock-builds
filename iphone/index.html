Lavalock for iPhone

Test build 1.0.1 (227). It installs only on the iPhones registered for testing.

Install Lavalock
  1. Open this page in Safari on the iPhone, tap Install Lavalock, then Install.
  2. If iOS says Developer Mode is required when you open the game: Settings, Privacy & Security, Developer Mode, turn it on and restart. After the restart, tap Turn On.
  3. Open Lavalock from the home screen.
