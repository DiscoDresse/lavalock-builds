# Lavalock test builds

Lavalock is a lava arena brawler for up to ten players, made by
[Disco Games](https://discogames.co.uk/games/lavalock/): knock each other into the lava with
spells, and buy new ones between rounds.

This repository holds only the test builds; iPhone builds come through TestFlight. Online
play runs on our own server, and practice works offline. When a new build comes out, older
ones stop playing online, so always take the newest. These links always give the newest:

- [Android](https://github.com/DiscoDresse/lavalock-builds/releases/latest/download/lavalock-android.apk)
- [Windows](https://github.com/DiscoDresse/lavalock-builds/releases/latest/download/lavalock-windows.zip)
- [Mac](https://github.com/DiscoDresse/lavalock-builds/releases/latest/download/lavalock-macos.zip)

Every build, with what's new in it, is on the
[releases page](https://github.com/DiscoDresse/lavalock-builds/releases).

## Installing

**Android:** open the Android link on your phone. Open the downloaded file, and when Android
asks, allow your browser (or file manager) to install apps. A new build installs over the
old one.

**Windows:** unzip the download and open `Lavalock.exe`. The test builds aren't signed, so
Windows may say "Windows protected your PC": choose *More info*, then *Run anyway*.

**Mac:** unzip the download and open `Lavalock.app`. The test builds aren't notarised, so
macOS says it can't check the app for malware. Choose *Done*, open *System Settings* →
*Privacy & Security*, scroll down and choose *Open Anyway* next to Lavalock. You only do this
once for each build.
